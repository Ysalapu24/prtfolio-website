# Yeshwanth Salapu — Portfolio Website Personal portfolio site built from scratch with HTML5, CSS3, and vanilla JavaScript. ## Live Site > Deploy via GitHub Pages — see setup below. ## Features - Responsive single-page design - Projects showcase with GitHub links - Skills section with tech stack - About section with background and stats - Contact section with email and social links ## Tech - HTML5 (semantic markup) - CSS3 (custom properties, grid, flexbox, animations) - Vanilla JavaScript - Google Fonts (Syne + DM Mono) ## Setup ```bash git clone https://github.com/Ysalapu24/prtfolio-website.git cd prtfolio-website open index.html ``` ## Deploy on GitHub Pages 1. Go to repo **Settings → Pages** 2. Set source to `main` branch, `/ (root)` 3. Save — your site will be live at `https://Ysalapu24.github.io/prtfolio-website` ## Author **Yeshwanth Salapu** B.S.
